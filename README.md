# UIA - Cátedra de Análisis de Crédito y Finanzas (ACF)
## Semana 4: Orientación del Crédito, Tasas Máximas y Regulación de Usura

Aplicación web educativa interactiva desarrollada en Python con **Streamlit** para la Universidad Internacional de las Américas (U.I.A.).

### 🎯 Marco Pedagógico
- **4 Principios de David Merrill:** Activación, Demostración, Aplicación e Integración.
- **Método de Feynman:** Explicación conceptual intuitiva mediante analogías de la vida cotidiana.
- **Evaluación Formativa Socrática & Mastery Viva:** Simulación de Comité de Crédito y defensa oral.

### 📚 Marco Normativo y Técnico
- **Ley N° 7472:** Promoción de la Competencia y Defensa Efectiva del Consumidor (Art. 36 bis, ter y 42).
- **Ley N° 9859:** Ley contra la Usura Crediticia en Costa Rica.
- **Banco Central de Costa Rica (BCCR):** Techos semestrales de tasas máximas de interés y Tasa de Política Monetaria (TPM).
- **CONASSIF / SUGEF:** Acuerdo CONASSIF 14-21 (Reglamento sobre cálculo de estimaciones crediticias).
- **Morales Castro:** *Crédito y Cobranza*, Capítulo 5 (Otorgamiento de crédito y fijación de sobreprecio).

### 🚀 Ejecución de la Aplicación
1. Ingresa a la carpeta del proyecto:
   ```bash
   cd S4ACF
   ```
2. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```
3. Ejecuta el servidor local:
   ```bash
   streamlit run app.py
   ```
